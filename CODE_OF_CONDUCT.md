# Code of conduct

We want this project to be welcoming and useful to everyone.

**Do:** be respectful, give specific and kind feedback, assume good intent, and accept differences in experience and opinion.

**Don't:** harass, insult, discriminate, doxx, or post sexual or hateful content.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders. Report a problem privately through a [GitHub security advisory](https://github.com/Guhan3132/Agentic-Component/security/advisories/new) or by contacting the maintainer through their GitHub profile.

This is adapted from the spirit of the Contributor Covenant 2.1.
